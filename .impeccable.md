# Impeccable Design Context — TideFocus

## Design Context

### Users
Primarily the author (daily focus sessions: pomodoro, tasks, notes, ambient sound) plus portfolio visitors who land on the public GitHub Pages deployment. Used in long sitting sessions on desktop; occasionally checked on a phone.

### Brand Personality
Calm, warm, unhurried. A beach at golden hour — soft glow, gentle motion, nothing shouting. The interface should feel like a place to settle into, not an app demanding attention.

### Aesthetic Direction
Apple-design version (Sept 2026). Two committed dark themes sharing one structure: **summer sunset** (default — warm oranges on deep plum) and **ocean** (teals on deep navy), switchable and persisted. Translucent materials (`backdrop-filter` blur + saturate, bright top edge, weight = hierarchy) over the animated scene (sun, palms, waves, particles). Typography: the platform system font (SF Pro on Apple devices) with size-specific tracking — negative on the large-title and thin tabular timer digits, ~0 on body, slightly positive on uppercase caption labels. Chrome is one SVG line-icon family (1.5–1.6 stroke), one button system (filled tint primary, tinted-fill secondary, circular icon buttons), and a fixed radius scale (28/20/14/10/7). Emoji stay only in toast copy (voice), never as UI chrome.

### Design Principles
1. **One system, two skins** — every component styles itself from semantic tokens (`--label-*`, `--fill-*`, `--mat-*`, `--tint`) that derive from the palette; nothing hardcodes a color.
2. **Chrome whispers, content glows** — the timer ring and the scene get the color; buttons and icons stay quiet and consistent.
3. **Respond on pointer-down** — every control has an instant `:active` state (scale 0.96–0.97, 100ms); no feedback waits for release.
4. **Springs for anything a finger can touch** — the segmented control thumb, the soundscape sheet, and task swipes run on a damping/response spring (`Spring` in index.html): they start from the on-screen value, take the release velocity, project momentum, rubber-band at edges, and can be grabbed mid-flight. CSS transitions are only for non-gesture UI, entering with `--ease-out` and exiting with its mirror `--ease-in`; reversible disclosures use the symmetric `--ease-inout`.
5. **Spatial consistency** — surfaces enter and exit along the same path and scale from the element that summoned them (`transform-origin` on the export popover, bottom-anchored sheet).
6. **Nothing clipped, nothing cramped** — no horizontal overflow at any width; touch targets ≥44px on mobile; inputs ≥16px on phones so iOS never zooms.
7. **Motion is tide, not fireworks** — slow scene loops (12–24s), and `prefers-reduced-motion` turns travel into cross-fades, `prefers-reduced-transparency` and `prefers-contrast: more` make materials solid.
